# Privacidade

## Dados coletados
Coletamos nome, CPF, endereço e histórico de compras para processar pedidos e emitir
notas fiscais, conforme a LGPD.

## Exclusão de dados
O titular pode pedir a exclusão dos dados pessoais pelo e-mail do encarregado. O prazo
de resposta é de 15 dias. Registros fiscais são mantidos pelo período exigido em lei.
